# Quick Vote

A simple, lightweight voting app built with plain HTML, CSS, and JavaScript. No frameworks, no dependencies — just open `index.html` in a browser.

## Features

- Create polls with a question and 2–6 options
- Vote with a single click
- Animated percentage bars show results instantly
- Reset and create new polls anytime

## Getting Started

```bash
# Clone the repo
git clone https://github.com/agnistack-org/voting-app.git
cd voting-app

# Open in browser
open index.html
```

Or use a local server:

```bash
python3 -m http.server 8080
# Visit http://localhost:8080
```
